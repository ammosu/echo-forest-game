# Echo Forest — 森林迷你遊樂場

五款可玩的瀏覽器遊戲：Anbo 森林音符冒險、三圈晨光盃賽車，融合種植守線與連鎖炸彈的森林爆破保衛戰，記憶合奏遊戲森林回音，以及音符接接樂。

## 開啟遊戲

需 Node.js 22.12 以上（或 Vite 7 支援的 Node 版本）。

```sh
npm install
npm run dev
```

開啟終端機顯示的網址，預設為 http://localhost:5173。手機與電腦在相同區域網路時，也可開啟終端機列出的 Network 網址。

```sh
npm run build      # TypeScript 檢查與正式打包
npm run preview    # 檢視正式打包
npm test           # Playwright 瀏覽器驗證，使用已安裝的 Google Chrome
```

## 中英文版本

每頁右上角的「EN／中文」按鈕切換語言，選擇會存在瀏覽器；也可在網址加 `?lang=en` 或 `?lang=zh`。沒有選過時依瀏覽器語言決定。字串以 `tr('中文', 'English')` 寫在使用處（`src/i18n.ts`）；Node 端測試會載入的賽道資料檔改用 `nameEn` 等欄位。

## 森林冒險操作

- ← / → 或 A / D：移動。
- 空白鍵、↑ 或 W：跳躍；較早放開可以縮短跳躍。
- Esc：暫停／繼續。R 或工具列的「重來」：整關重新開始。
- 觸控裝置：同時按住方向與跳躍。放開或取消觸控會清除輸入。
- 音效預設關閉，可在工具列開啟。切到背景會自動暫停。

共 20 顆音符、3 顆愛心，包含樹樁、空隙、彈跳蘑菇、小刺球、移動平台、中途營地與 Owl 終點。收集音符為分數，不會因漏收卡住終點。失去愛心回起點或已啟用的營地；愛心用盡可重新開始。通關紀錄保存在本機瀏覽器，優先記錄音符較多、同分時較快的成績。瀏覽器禁用儲存仍可遊玩。

右上「賽車工坊」可切換八個角度並下載原始樣張。工坊開啟時暫停遊戲，關閉後恢復原狀。

## 森林賽車

開啟 `/race.html`，或從頂部選單點「森林賽車」。正式打包會同時輸出五個遊戲入口。

- 玩家：Anbo／苔綠號。對手：Angoo／紅葉號、Anmi／蜂蜜號、Anje／微風號。
- Three.js 立體追尾視角，三圈閉合環線；晨光林道、蕨葉彎道、金色花谷三個景觀區段。
- ← / → 或 A / D：轉向。↓ / S：煞車。自動油門預設開啟，關閉後以 ↑ / W 或手機油門按鈕加速。
- Space 或 Shift＋轉向：甩尾。彎道內蓄力超過 0.65 秒，放開即可短暫加速；碰撞、低速或離開賽道會中斷蓄力。
- 碰到道具箱可持有一份回聲能量；E、畫面道具按鈕或觸控道具鍵使用。快速按下也會保留輸入到下一個物理更新。
- 加速帶提供短暫加速；草地減速；樹樁會擋住車身，轉向可繞開；撞到對手會減速並分開車身。
- Esc／暫停：同時凍結玩家、對手、倒數與計時。切出視窗自動暫停。重來會完整清除上一場比賽狀態。
- 支援手機雙指操作、直向／橫向排版，以及支援瀏覽器的全螢幕模式。

比賽以固定 120 Hz 步進更新，48000 單位／圈，依序通過 12 個四分之一圈檢查點後完成三圈。畫面速度為遊戲單位換算的 km/h 顯示，不是現實車輛模擬。AI 依各車性能持續前進、變換車道並避障，沒有傳送或依玩家圈數重設對手進度。結算提供名次、逐圈時間與本機最快總時間；尚未完賽的對手依當時進度排列並明確標示。

### 森林賽車 Three.js 版

- 真正閉合的立體環線、透視追尾鏡頭、低多邊形森林、晨光陰影，以及三種景觀區段。場景和小地圖共用同一條等弧長賽道。
- 四台立體車身分別配上原始角色正面／背面像素圖；車身轉向、甩尾角度、蓄力火花和加速尾焰會同步遊戲狀態。角色仍是紙片素材，未製作骨架模型。完賽的 AI 車退出場景，避免停在終點擋路。
- 賽道外側有實體木護欄，接觸位置會扣除車身寬度。撞牆時產生火花、短暫車身／鏡頭震動、向內反彈與頭頂星星；依撞擊強度暈眩約 0.3–0.7 秒，期間停止前進並暫停油門、轉向和道具，其他車與比賽計時繼續。暫停比賽會凍結暈眩倒數，重開則清除反彈和暈眩狀態。
- 車輛互撞依接觸方向、相對速度與車重計算衝量，兩車的速度／側向反彈與視覺震動分別更新。調校車重：苔綠號 160、紅葉號 195、蜂蜜號 140、微風號 115；輕車更容易被推開，嚴重追撞也會短暫暈眩。減少動態效果設定會關閉碰撞鏡頭／車身震動和星星旋轉，保留提示與停頓。
- 能量箱有金色發光核心、旋轉光框、光圈和環繞亮點，收集後消失並在車身周圍散出亮點；同一圈不能重複收集。加速帶每圈每塊只觸發一次。
- `src/racing-collision.ts` 以模型尺寸定義車身、樹樁、道具和加速帶的接觸範圍，甩尾時擴大車身側向範圍。連續掃掠判定涵蓋高速穿越與側向進入；車輛碰撞包含 AI 互撞、套圈與起終點接縫。樹樁阻擋前進，車輛接觸會分離，不靠瞬間穿透來通行。
- 靜態森林、車身和道具重複零件採實例合併；像素比例上限 1.5，陰影貼圖 1024。重開復用場景，離開／銷毀時可釋放材質、幾何、貼圖和事件。減少動態效果設定會關閉能量箱旋轉起伏、鏡頭速度視角變化與車身傾斜。
- 支援手機雙指操作、直橫向和全螢幕；開始／重開會將手機畫面捲到遊戲區。需要 WebGL 2，建立失敗或繪圖環境中斷時顯示持續的重新載入按鈕並停止比賽。

## 森林爆破保衛戰

開啟 `/defense.html`，或從任一遊戲頂部選單點「爆破保衛戰」。單人 9 × 5 格立體戰場，守住生命樹並撐過五波進攻。

- 方向鍵 / WASD：移動；角色可穿過植物，枯木與已放置的炸彈會擋路。
- 1 / 2 / 3：選松果射手、樹樁守衛或冰霧蘑菇。點草地種植，或 Enter 在腳下種植；最右一列為怪物入口。
- Space：免費放炸彈，同時最多三顆；兩秒後沿十字延伸兩格，遇到枯木停止並摧毀它。爆風可引爆其他炸彈。
- 爆風傷害玩家、保護己方植物。三顆愛心耗盡或生命樹耐久歸零即失敗；被炸到後有兩秒無敵時間。
- 每三秒獲得 15 露珠；擊退敵人獲得 12、炸開枯木獲得 20、波次間獲得 65。植物消耗露珠，不能在占用格重複種植。
- 三種敵人：普通怪、快跑怪、裝甲怪。怪物沿行前進，遇到植物停下攻擊；冰霧射擊降低移速。
- 初始整備 12 秒，第 2–5 波前依序整備 10／8／8／6 秒，可點「提前迎戰」開始。五波共 65 隻敵人，全部解決才完成；突破防線的敵人會扣生命樹耐久。
- Esc / 暫停凍結所有倒數與模擬；切到背景自動暫停。重來完整重設本局，最高分保存在本機；停用儲存仍可玩。
- 手機提供方向按鈕、種子卡、點格種植、腳下種植與放炸彈按鈕。音效預設關閉。

### Three.js 第一版

- 固定斜俯視正交鏡頭、立體草地與木質底座、低多邊形森林、植物和三種敵人；日光與即時陰影。
- Anbo 沿用原始像素素材，以面向相機的紙片角色呈現；金色光圈標示實際所在格。此版沒有骨架角色模型。
- 滑鼠與觸控透過射線對地面選格；金色高亮代表可種植，紅色代表占用、入口或露珠不足。
- 炸彈周圍十段亮點顯示倒數，橘色地格預告十字爆風，遇枯木停止；連鎖爆炸、冰霧命中與血量條會同步反映引擎狀態。
- 手機開始或重開會捲到遊戲區；直向與橫向縮放後重新計算鏡頭及選格座標。
- 需要支援 WebGL 2 並可建立繪圖環境的瀏覽器。建立失敗顯示恢復提示；繪圖環境中斷時暫停模擬並提供重新載入。
- 靜態景物採實例合併，幾何與材質共用；移除敵人或重開時清除對應場景物件。渲染像素比例上限為 1.5，陰影貼圖為 1024。尊重減少動態效果設定，關閉非必要的敵人起伏與火焰縮放。

`src/defense-engine.ts` 為獨立遊戲邏輯；`src/defense-view.ts` 負責 Three.js 場景、模型、選格與狀態同步；`src/defense.ts` 與 `src/defense.css` 負責介面、音效與輸入。森林賽車也使用 Three.js；森林冒險仍使用 Phaser。兩款立體遊戲都不需要外部模型服務。

## 角色與車輛自由搭配的擴充方式

`src/racing-data.ts` 已將 `RaceEntry.characterId` 和 `RaceEntry.vehicleId` 分開。角色識別、車輛性能和素材對應不互相綁死；改車輛性能不需改角色設定。

**目前可玩的版本使用四組固定搭配，尚未提供自由選角／選車。** Three.js 車身與角色紙片已分離，資料仍保留角色與車輛的獨立識別；未來可以加上選角／選車介面。若改用完整立體角色，仍需製作模型、坐姿與動作。

如果使用 Blender，可把車輛的座位設定為固定掛點，角色共用相容的坐姿骨架，固定相機、燈光與八方向輸出；像素修整後匯入相同的分層格式。目前沒有使用 Blender MCP。

## 驗證方式

測試的通關流程只讀取開發模式的角色位置，透過鍵盤移動與跳躍穿過實際關卡；沒有傳送角色、修改愛心或直接觸發勝利。正式打包不公開這個診斷介面。

冒險測試包含圖片載入、收集、跳躍、暫停凍結、重開計時、三次掉落、通關與儲存、工坊八角度及恢復、手機雙指與取消觸控。賽車測試包含倒數、暫停、道具、甩尾蓄力加速、草地減速、煞車、手動油門、背景暫停、三圈完整比賽／12 個檢查點／逐圈時間加總／紀錄儲存，以及手機雙指與橫向排版。賽車完整測試也只使用唯讀診斷與鍵盤操作，沒有修改位置、時間或圈數。`tests/evidence/` 保存可檢視的測試畫面。Google Fonts 為視覺增強，載入失敗時使用系統字型。

保衛戰的 `tests/defense.spec.ts` 驗證資源／占用規則、減速與阻擋、連鎖爆炸、枯木遮擋、己方植物免傷、玩家受傷、暫停、失敗重設，以及桌面鍵盤與手機真實觸控。完整五波測試透過正常種植方法、正常資源和固定時間步進加速模擬，沒有增加資源或直接設定勝利；瀏覽器測試另驗證結算及紀錄儲存。此模擬通關測試不等同真人即時操作。正式打包移除保衛戰開發診斷介面。

Three.js 的 `tests/defense-3d.spec.ts` 額外驗證四角點格、三種植物、占用與入口拒絕、視窗旋轉後定位、真實觸控種植、靜態場景繪製次數、枯木遮擋的爆風預覽、連鎖火焰、敵人／彈丸場景同步、重開清理、失敗結算與 WebGL 不可用／中斷處理。特效測試使用明確的引擎場景 fixture；五波通關測試仍以正常資源及種植規則加速模擬。正式打包不公開 `__defense` 或 `__defenseView` 診斷工具。桌面與手機畫面保存在 `tests/evidence/defense-*.png`；手機測試為 Chrome 觸控模擬，尚未在實體手機量測效能。

賽車的 `tests/race-3d.spec.ts`、`tests/race-collision.spec.ts` 額外驗證高速掃掠、擦邊未碰、側向進入、樹樁阻擋與脫困、所有道具／加速帶、重複領取防護、車輛追撞／側撞／套圈／接縫／重疊恢復，以及場景位置同步、發光拾取物消失與收集特效、暫停凍結、重開資源復用、減少動態效果、視窗縮放與 WebGL 失敗／中斷。碰撞邊界使用明確的引擎 fixture；完整三圈仍透過正常鍵盤操作完成。`tests/evidence/race-3d-*.png` 保存立體賽車畫面；手機為 Chrome 觸控模擬，尚未量測實體手機效能。正式打包不公開 `__race` 或 `__raceView` 診斷工具。

`tests/race-production.spec.ts` 會重新建立正式包、啟動臨時預覽伺服器，驗證可正常起跑／暫停、沒有素材錯誤且未暴露開發診斷介面，並更新 `tests/evidence/race-production.png`。

`tests/race-impact.spec.ts` 驗證左右護欄阻擋／反彈、暈眩停止前進與道具鎖定、恢復／暫停／重開、重量和速度對衝量的影響、輕車較大的實際反彈，以及正常鍵盤撞牆後的暈眩星星。`tests/evidence/race-wall-impact.png` 保存實際撞牆畫面；既有拾取測試透過唯讀狀態與鍵盤修正碰撞後的方向，不修改車輛位置。

## 森林回音

開啟 `/echo.html`，或從任一遊戲選單進入。Owl 指揮 Anje、Ansey、Anka 與 Anzo，玩家記住夥伴亮起的順序，再點擊角色或按 1–4 回應。八段旋律從兩個音逐步增加到九個音，每段沿用上一段再增加一音。

- 開始前可點角色試聽；音效使用瀏覽器合成音色，並非真實樂器錄音。聲音可關閉，燈光、形狀及角色名稱仍提供提示。
- 演奏期間鎖定輸入；答錯可重聽原段，不扣生命、不限時間。答對後按「接下一段」繼續。
- Esc 或按鈕暫停；離開分頁自動暫停，繼續時從頭重播未完成段落。重開會取消舊的播放與音效。
- 完成段數的最佳紀錄儲存在本機，禁用儲存仍可遊玩。
- 目前使用原始像素角色與森林背景，尚未接入製作中的 3D 模型。尊重減少動態效果設定，保留必要燈光提示。
- `src/echo-engine.ts` 管理順序與段落規則；`src/echo.ts` 管理播放、音色、輸入；`src/echo.css` 管理舞台與手機排版。

## 音符接接樂

開啟 `/catch.html`，或從任一遊戲導覽進入。第五款遊戲採用經典接物玩法，主題是接住旋律、完成森林演出，和「森林回音」的順序記憶形成區別。畫面沿用森林綠、晨光金與原始像素角色，灰色方形雜音和金色圓形音符同時用形狀、符號區分。

### 玩法與內容

- Anbo、Anmi、Anka、Anzo 四位可選夥伴，能力相同。原始角色素材先完成遊戲流程，尚未整合 Blender 造型稿或骨架動畫。
- 一局 48 秒，三個 16 秒樂段：晨光落下、林間追光、一起合奏。每段有 12、16、20 個音符，間隔從 1 秒縮短為 0.8、0.65 秒；合計 48 個音符與 12 個雜音。
- 樂譜為原創固定路線與短旋律，接住時播放合成音色；沒有背景音檔或商用曲目。遊戲按位置接物，並非要求按拍的節奏判定。相同樂譜可重玩練習。
- 金色音符每個 100 分；連擊每次多 10 分，加成上限 100 分。漏接中斷連擊，碰灰色雜音扣 50 分並中斷連擊，分數最低為零。不扣生命、不提早淘汰。
- 接住 12 / 28 個音符得到一 / 二星；三星需接住至少 44 個，且碰雜音不超過 1 次；全接最高 9,050 分。結算顯示分數、接住數、最高連擊、漏接及雜音次數，支援重玩與重新選角。

### 操作與恢復

- 左右鍵或 A / D 持續移動；1–4 或下方四個按鈕移到指定位置；滑鼠或手指可在舞台點選或拖曳。角色移動有速度上限，不會瞬間傳送。
- Esc 或工具列暫停；失焦或隱藏分頁自動暫停並釋放輸入。暫停凍結落下位置、計時、分數和角色。重開會重設樂譜、音效、輸入與計分。
- 聲音可關閉；角色回饋尊重減少動態效果設定，必要的落下運動保留。最高分儲存在本機，停用儲存仍可完整遊玩。
- `src/catch-engine.ts`：固定樂譜、移動、接觸判定與計分。`src/catch.ts`：角色選擇、操作、合成音效、畫面與結算。`src/catch.css`：舞台、直橫向及手機排版。

### 驗證

`npx playwright test tests/catch.spec.ts` 驗證完整樂譜可達性、精確計分、漏接／雜音、暫停與重設、正常鍵盤完成整首曲子、手機觸控／拖曳、靜音、停用儲存、畫面旋轉及 GitHub Pages 子路徑正式包。瀏覽器通關控制器只讀開發模式狀態，再透過正常鍵盤移動，沒有修改位置或分數；正式包不公開 `__catchState`。截圖保存在 `tests/evidence/catch-*.png`。手機測試為 Chrome 模擬，尚未在實體裝置量測。

## 雪林滑降

開啟 `/ski.html`，或從森林地圖的「雪松山頂」進入。第六款遊戲是 three.js 3D 滑雪下坡：1,050 公尺固定雪道分三段（林間緩坡 13°、雪松旗門 16°、冰瀑跳台 19°），26 個紅藍旗門、60 個音符、2 座跳台。

- 操作：←/→ 或 A/D 轉彎，↑/W 壓低加速（較難轉彎），↓/S 煞車，空中按 Space 翻轉，Esc 暫停。手機用雙軸搖桿（上推壓低、下拉煞車）與「特技」按鈕。
- 規則：漏旗 +3 秒；撞樹或岩石跌倒減速；碰護網減速；冰面難轉彎、鬆雪拖慢速度；翻轉沒完成就落地會摔倒；落地方向偏太多會減速。
- 星等：完賽一星；70 秒內且漏旗不超過 4 個二星；60 秒內、旗門全過、音符七成三星。最佳時間存在本機。
- 角色 Anje（滑雪背影素材）、Anbo、Anmi、Anbi，能力相同。地圖地標 `assets/ui/forest/landmark-ski.png` 由 Codex 內建 image_gen 生成，原圖在 `assets/generated/ski-ui/`。
- `src/ski-engine.ts`：雪道、物理、判定與計分（可在 Node 測試）。`src/ski-view.ts`：3D 場景與追尾相機。`src/ski.ts`：介面、輸入與合成音效。`src/ski.css`：版面與手機排版。

`npx playwright test tests/ski.spec.ts` 驗證雪道固定且路線淨空、自動駕駛全旗門零跌倒完賽、壓低加特技可拿三星、旗門／撞樹／護網／翻轉失敗判定、倒數、暫停與重來、鍵盤完整通關與紀錄、手機搖桿與特技按鈕。截圖在 `tests/evidence/ski-*.png`。

## 難度微調（2026-10-03）

開頭保留熟悉操作的空間，後半段增加預判與準確度要求：

- 森林冒險：營地後增加一組巡邏刺球；後段刺球速度由 33 提到 43，移動平台由 36 提到 46。三顆愛心與營地重生保留。
- 森林賽車：對手第一圈基礎速度提高 3%，後兩圈提高 5%，彎道減速略減；會朝前方加速帶靠近，實際碰到才取得 1.1 秒、18% 的加速，每圈每塊只能使用一次。
- 保衛戰：前三波仍逐步介紹怪物；第四、五波增加裝甲與快跑怪比例。出怪間隔由前兩波 1.9 秒，逐步縮短至 1.75／1.6／1.45 秒。總怪物數、初始資源與血量不變。
- 森林回音：前兩段維持每音 760 毫秒、提示 470 毫秒；之後逐段縮短，最後一段為每音 550 毫秒、提示 320 毫秒。聲音同步縮短，重播與不限時作答保留。
- 音符接接樂：第一段保留原路線；後兩段加入跨兩格與三格移動，雜音由每四音一次提高到每兩音一次，仍保持整張樂譜可全接。三星需接住至少 44／48 音，且碰雜音最多一次；一、二星維持 12／28 音。

既有本機最佳紀錄保留；這次未新增排行榜或分開記錄歷史版本成績。

## 森林賽車跳台

每圈新增三座可選木跳台：晨光小跳台（右側）、蕨葉飛躍（左側）、花谷大跳台（右側）。沿地面從旁邊繞過也能完成比賽；每條可選賽道都使用這三座跳台；目前沒有賽途中切換的獨立岔路。

- 正向開過跳台頂端自動起跳，無須新增按鍵。速度至少 1600 遊戲單位才有向上躍起的力量；低速只會滑下。
- 騰空高度依重力更新，較快的車飛得更遠。空中轉向與彎道側移減至地面的 65%，不能蓄甩尾加速。
- 正常起跳後，未撞擊且落在路面內側（橫向絕對值不超過 0.9），獲得 0.8 秒加速；成功做起跳特技則延長到 1.4 秒。側邊掉落或落在草地不給獎勵。
- 車輛高度差超過 1.5 時不互撞，高於 1.5 可越過樹樁；加速帶只在近地面觸發。外側護欄仍限制空中橫向範圍。
- 對手也會選擇部分跳台，使用相同騰空與落地規則。暫停凍結飛行，重開清除高度與飛躍紀錄。
- 木板斜坡、金色箭頭、路旁標示與小地圖標記指引跳台位置；畫面顯示空中狀態。減少動態效果模式保留必要的車輛升降，取消額外鏡頭升降與俯仰。

`tests/race-jumps.spec.ts` 驗證起跳、落地、旁路、低速、跨圈、無獎勵落地及正常鍵盤飛躍／暫停／重開；`tests/evidence/race-jump.png` 保存實際騰空畫面。

## 賽道選擇與起跳特技

參考 [任天堂《Mario Kart 8 Deluxe》駕駛技巧介紹](https://www.nintendo.com/jp/ichikara/aabpa/index_en.html) 中「抓準起跳時機換取落地加速」的原則，使用回聲森林自己的賽道、角色與視覺素材。

- 賽道選單：晨光環線（均衡）、花谷巡遊（寬緩連彎）、蕨葉溪谷（連續反向彎）。三者使用不同的閉合路徑控制點，場景、車輛、碰撞和小地圖共用該路徑；並非只換名稱。仍共用三圈、每圈 48000 遊戲距離與道具／跳台配置。
- 跳台離地前 0.18 秒或離地後 0.22 秒內，重新按一次 Space／Shift／觸控「甩尾／特技」可做特技。持續按住不會自動觸發，每次飛躍只能成功一次。
- 成功時車身旋轉並顯示提示，穩定落地加速 1.4 秒；普通落地維持 0.8 秒。碰撞或落在草地不給獎勵。減少動態效果模式保留文字提示，取消車身旋轉。
- 三條賽道各自保存最佳時間；晨光環線保留既有紀錄。網址 `?course=meadow` 與 `?course=fern` 可直接開啟其他賽道，不支援的參數回到晨光環線。
- `tests/race-courses.spec.ts` 透過正常方向鍵完成兩條新賽道的三圈，驗證路徑確實不同、獨立紀錄及手機選單；跳台測試另涵蓋特技時機與手機觸控特技。

## 葉片滑翔翼

高速離開三座跳台會自動展開與車色搭配的葉片滑翔翼。角色與車身保持在翼下，空中可左右轉向；落地自動收翼。低速滑下或從跳台側邊掉落不會開翼。

- ↑／W 俯衝：更快下降，空速最多提高約 10%。↓／S 拉升：降低空速、增加升力，延長滑翔；在地面仍對應油門／煞車。
- 手機於滑翔時顯示「俯衝」「拉升」按鈕，落地恢復原標示；自動油門開啟時也可控制俯衝。
- 升力最多維持至離地後 2.6 秒，之後逐漸落地，不能長按拉升無限飛行。翼面會保持展開直到接地；撞暈或失速會失去升力。
- 原有起跳特技、普通／特技落地加速與空中碰撞規則保留。對手套用相同滑翔物理，預設平飛。
- 暫停會凍結高度、升降與翼面展開進度；重開收翼並清空滑翔狀態。減少動態效果模式立即展翼，保留必要位移，取消翼面傾斜與額外鏡頭動作。

跳台測試包含滑翔升降、落地收翼、拉升時間上限、空中油門／煞車語意、手機按鈕切換、暫停與重開。
